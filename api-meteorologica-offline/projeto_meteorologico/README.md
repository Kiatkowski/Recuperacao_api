# O que é o Código

O código servirá para receber dados meteorológicos de uma api local, para monitorar uma cidade desejada.

# COMO RODAR?


1 - cd api-meteorologica-offline

2 - pip install -r requirements.txt

3 - uvicorn app.main:app --reload

4 - cd projeto_meteorologico

5 - python -m streamlit run frontend_01.py
